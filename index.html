Desktop app

PDF Editor

A personal, fully offline PDF editor for Windows 11, written in Python. Nothing is uploaded anywhere.

Features

  • Tabbed multi-file editing, drag and drop, and undo/redo for every change
  • Edit existing text in its closest matching font, size and colour, or add new text
  • Highlight, draw, add shapes, notes and comments, fill and create form fields, and add signatures
  • Reorder, rotate, merge, split and extract pages
  • Real redaction that removes the text, image pixels and drawings underneath
  • Watermarks, headers and footers, page numbers, compression, and AES-256 password protection
  • Export pages to images, combine images into a PDF, and print

Engineering

  • Python with PySide6 (Qt), PyMuPDF and fontTools, about 7,900 lines across the core and UI packages
  • Font system that matches fonts in order: embedded in the PDF, installed on Windows, then a bundled font library. It reports any missing fonts.
  • Automated smoke tests that build a sample PDF and exercise every main feature
  • Compiled into a native Windows app with Nuitka

Game mashup mod prototype

A private, non-commercial, offline Naruto × Elden Ring fan mashup. It's in early research and prototype stage. No game assets or downloads are shared.

  • Python memory-reader toolkit for the PC fighting game that only reads (it never writes to, hooks or injects into the game). It dumps, diffs and follows pointers to find character health, position and facing direction.
  • Per-character profiles, with logging and calibration tools such as a "spin test" that finds the facing direction
  • A bridge that publishes the character's live position to a shared-memory block 60 times a second for the mashup side to use
  • Early C++ DLL projects in Visual Studio, plus unit tests for the reader, profiles and bridge
